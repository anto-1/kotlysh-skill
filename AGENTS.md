# Kotlysh skill

This repository is an agent skill for Kotlysh. Its instructions are in
[SKILL.md](SKILL.md): read that file in full before writing or running a
Kotlysh task, and run tasks with `scripts/kotlysh-run`.

To make the skill available in other projects, run
`scripts/install-agents-md`. It adds a short pointer to this checkout to an
`AGENTS.md` file, by default the global one of Codex.
